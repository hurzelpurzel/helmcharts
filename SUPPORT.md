# Support

This is a small personal project maintained by the repository owner.

- **Bug reports & feature requests:** open a [GitHub issue](https://github.com/hurzelpurzel/helmcharts/issues) and use the provided templates.
- **Questions:** check the chart's own `README.md`/`values.yaml` first. For app-specific questions (e.g. how the upstream service behaves), prefer the upstream project's issue tracker linked from `README.md`.
- **Security issues:** see [SECURITY.md](SECURITY.md).
